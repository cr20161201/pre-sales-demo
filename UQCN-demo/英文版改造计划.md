# UQCN Demo 英文版改造计划

## 背景

当前 UQCN Demo 明确用于售前演示，目标是快速提供中英双版本，而不是把静态 demo 改造成长期维护的完整国际化应用。

现有实现是单 HTML + 单 JS + 单 CSS：

```text
demo/UQCN-demo/
  index.html
  app.js
  styles.css
  assets/
  产品方案.md
```

其中 `app.js` 同时包含：

- 产品与任务数据
- 页面状态
- 渲染模板
- 交互绑定
- 中文业务枚举与展示文案

很多中文字符串既是展示文案，也是逻辑判断值，例如：

- `待审核`
- `审核通过`
- `已通过`
- `生成中`
- `全部`
- `刺绣`
- `左胸`
- `尺码展示图`

因此，短期不建议直接做统一 `i18n` 字典，否则需要先重构大量枚举与判断逻辑。

## 推荐方案

采用售前 demo 优先的双应用方案：

```text
demo/UQCN-demo/
  index.html
  app.js           # 中文版应用
  app.en.js        # 英文版应用
  styles.css       # 中英文共用基础样式
  styles.en.css    # 英文版样式补丁
  assets/
  产品方案.md
  英文版改造计划.md
```

核心原则：

- 中文版 `app.js` 尽量少动。
- 英文版从 `app.js` 复制为 `app.en.js` 后翻译。
- `index.html` 根据 URL 参数或路径加载对应 JS。
- 英文版额外加载 `styles.en.css`，只处理英文字符长度导致的布局问题。
- 语言切换通过页面跳转完成，不追求无刷新保留状态。

## 访问方式

建议使用 URL 参数：

```text
index.html?lang=zh
index.html?lang=en
```

默认语言为中文：

```text
index.html
```

加载逻辑：

- `lang=en` 时：
  - 设置 `<html lang="en">`
  - 加载 `styles.en.css`
  - 加载 `app.en.js`
- 其他情况：
  - 设置 `<html lang="zh-CN">`
  - 加载 `app.js`

## 改造步骤

### 第 1 步：增加语言加载器

修改 `index.html`：

- 移除固定加载 `app.js` 的脚本标签。
- 增加一段很小的 loader。
- 根据 `URLSearchParams(location.search).get("lang")` 判断语言。
- 动态插入英文样式补丁和对应 JS。

预期结果：

- `index.html` 打开中文版。
- `index.html?lang=en` 打开英文版。
- 两个版本共用同一套静态资源。

### 第 2 步：复制英文应用

新增：

```text
app.en.js
```

初始内容从 `app.js` 复制。

然后在 `app.en.js` 内完成英文翻译，优先覆盖售前演示会实际看到的页面：

1. 入口页
2. 顶栏与账号菜单
3. 运营端 AI 工具
4. 任务列表
5. 素材图片 / 审核抽屉
6. B 端团定设计工具
7. AI 运营管理后台

注意：英文版内部可以继续使用英文字符串作为逻辑值，不强行抽象 key。

### 第 3 步：增加语言切换入口

中文版：

- 顶栏或入口页增加 `EN` 按钮。
- 点击跳转：

```js
location.href = "index.html?lang=en";
```

英文版：

- 对应位置增加 `中文` 或 `CN` 按钮。
- 点击跳转：

```js
location.href = "index.html?lang=zh";
```

切换语言时页面会刷新，这是售前 demo 可接受的取舍。

### 第 4 步：增加英文样式补丁

新增：

```text
styles.en.css
```

只处理英文版布局问题，不复制整份 `styles.css`。

重点关注：

- 侧边栏宽度
- 顶栏按钮宽度
- 首页入口卡片标题换行
- 工具卡片标题和描述换行
- 筛选 chip 换行
- 表格和任务卡片文案溢出
- 抽屉字段 label 过长
- 设计工具步骤条文案过长

初始补丁建议：

```css
html[lang="en"] .side-nav {
  width: 260px;
}

html[lang="en"] .side-link span,
html[lang="en"] .primary-btn,
html[lang="en"] .small-btn,
html[lang="en"] .ghost-btn,
html[lang="en"] .filter-chip,
html[lang="en"] .choice-pill {
  white-space: normal;
}

html[lang="en"] .task-filter-bar,
html[lang="en"] .head-actions,
html[lang="en"] .drawer-actions {
  flex-wrap: wrap;
}

html[lang="en"] .entry-card h2,
html[lang="en"] .ai-tool-card h2,
html[lang="en"] .designer-stepper strong {
  line-height: 1.2;
}
```

实际补丁以页面检查结果为准，避免过早扩大样式改动。

### 第 5 步：逐屏验收

英文版至少检查以下路径：

1. 首页三入口
2. 运营端 AI 工具列表
3. 运营端 AI 工具工作台
4. AI 创建抽屉
5. 任务列表与任务详情抽屉
6. 素材图片列表与审核详情抽屉
7. B 端团定设计工具四步流程
8. 后台审核中心
9. 后台员工管理
10. 后台角色管理
11. 后台 Prompt 管理

每个页面检查：

- 文案是否完整英文
- 按钮文字是否溢出
- 卡片高度是否明显错乱
- 侧边栏是否拥挤
- 弹窗和抽屉是否可读
- 关键交互是否仍能点击
- 状态颜色是否仍然正确

## 翻译范围建议

### 必须翻译

- 页面标题
- 导航菜单
- 入口卡片
- 按钮
- 筛选项
- 状态
- 任务标题
- AI 工具名称
- AI 工具描述
- 表单字段
- 审核动作
- 设计工具步骤
- 后台模块

### 可以保留

- UNIQLO 品牌名
- Logo 文件名
- 图片资源文件名
- 产品编号、任务编号、员工编号
- `Prompt`
- `Logo`
- `SKU`
- `AI`
- `ZIP + CSV`

### 可按英文语境调整

部分中文不是逐字翻译，而应调整为售前更自然的英文：

```text
运营端 AI 工具       -> Operator AI Workspace
B端团定设计工具      -> Custom Order Design Tool
AI运营管理后台       -> AI Operations Admin
素材图片             -> Generated Assets
审核中心             -> Review Center
尺码展示图           -> Size Display Image
材质展示图           -> Material Detail Image
指定模特图           -> Assigned Model Image
商品对比图           -> Product Comparison Image
结果包下载           -> Result Package Download
```

## 风险与取舍

### 优点

- 改动少，适合快速交付售前英文版。
- 中文版现有逻辑风险低。
- 英文版可独立修正文案和布局。
- 不需要引入框架或 i18n 依赖。
- 后续可以渐进式抽象，不影响当前交付。

### 缺点

- 中英文两份 JS 需要同步维护。
- 语言切换会刷新页面。
- 如果后续长期迭代，双份应用会产生重复修改成本。

### 可接受原因

当前目标是售前演示，不是长期产品化国际化。

在这个阶段，演示稳定性和交付速度优先于架构完美度。

## 后续升级路径

如果 demo 后续变成长期产品原型，再考虑重构为真正多语言架构：

- 用稳定 key 替代中文业务值。
- 把状态、类型、筛选项改成 `{ key, label }`。
- 建立 `i18n.zh` 和 `i18n.en` 字典。
- CSS 使用稳定状态 key，例如 `data-status="approved"`。
- 产品数据与 UI 文案分离。

届时可以从 `app.en.js` 反向沉淀英文文案字典，而不是重新翻译。

## 建议执行顺序

1. 修改 `index.html` 加语言 loader。
2. 复制 `app.js` 为 `app.en.js`。
3. 在中英文版本加入语言切换按钮。
4. 翻译 `app.en.js` 的核心售前路径。
5. 新增 `styles.en.css`。
6. 逐屏检查英文版布局。
7. 根据实际溢出点补英文 CSS。
8. 最后回归中文版，确认没有被影响。

## 验收标准

- `index.html` 默认打开中文版。
- `index.html?lang=en` 打开英文版。
- 中英文版本都能进入三个主入口。
- 英文版核心售前路径无明显中文残留。
- 英文版无明显文字溢出、遮挡、按钮挤压。
- 中英文语言切换可用。
- 中文版现有页面和交互保持可用。
