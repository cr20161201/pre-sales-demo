# 足球服定制商城网站开发项目清单

## 1. 项目范围说明

本项目用于建设足球服定制商城网站，优先交付 PC 用户端商城与后台管理端。系统核心能力包括商品展示、3D 球服定制、下单支付、订单管理、生产资料下载、多语言内容管理等。

3D 定制能力基于现有成熟 3D SDK 实现，本项目主要负责商城系统开发、3D SDK 接入、SDK 配套 Cloud 平台 API 对接，以及相关业务流程打通。

## 2. 交付范围

| 交付内容 | 说明 |
| :--- | :--- |
| PC 用户端商城 | 商品浏览、商品详情、3D 定制、购物车、下单、支付、订单查看、多语言切换 |
| PC 后台管理端 | 商品管理、3D 定制资源管理、订单管理、生产资料下载、内容运营配置、多语言内容维护 |
| 3D SDK 对接 | 接入现有 3D SDK，实现模型预览、定制交互、效果保存等能力 |
| Cloud API 对接 | 对接 3D SDK 配套 Cloud 平台，获取模型、模板、材质、可定制区域等资源 |
| 支付接口对接 | 国内支持微信支付、支付宝；海外支持 PayPal |
| 多语言支持 | 支持中文、英文内容展示与后台维护 |
| 生产资料下载 | 后台按订单下载 SDK 生成的 Excel 文件及模型文件 |

## 4. 售后与退款边界

本系统支持用户提交售后/退款申请，后台可进行人工审核、记录处理结果、更新订单售后状态。

本项目不包含系统内自动退款接口。实际退款需运营人员前往对应支付平台后台人工处理，包括微信支付、支付宝、PayPal 等平台。

定制商品进入生产后，原则上不支持用户自行修改定制内容；退款、换货、修改参数等需求需由后台人工审核。

| 不包含项 | 说明 |
| :--- | :--- |
| 3D SDK 自身开发 | 本项目只对接现有 SDK，不从零开发 3D 引擎 |
