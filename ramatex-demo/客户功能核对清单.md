# Ramatex 最简功能点核对清单

本文基于当前前台 demo 梳理，用于和客户确认正式系统的最简功能范围。  
本文不是完整 PRD，不展开支付、物流、库存、财务、CRM、报表等通用电商能力。

## 1. 基础规则

| 规则 | 说明 | 状态 |
| --- | --- | --- |
| 品牌是核心数据归属 | 品牌空间、品牌款式、品牌面料、品牌视频、品牌图案、品牌订单都需要归属到具体品牌 | 已确认 |
| 公开站内容单独管理 | 公开首页展示的 Banner、款式、视频、面料作为公开内容维护 | 已确认 |
| 品牌空间内容隔离 | 不同品牌只能看到自己品牌下的内容和订单 | 已确认 |
| 凭证进入品牌空间 | 凭证用于进入对应品牌空间，最简版先不做复杂个人账号体系 | 已确认 |
| 不提供询盘查看 | 后台不提供询盘列表、询盘详情、询盘跟进功能 | 已确认 |
| 订单按品牌归属 | 品牌空间提交的选品单/订单归属到当前品牌 | 已确认 |

## 4. 定制配置最简规则

| 配置项 | 当前结论 | 说明 |
| --- | --- | --- |
| 可配置区域是否固定 | 不固定 | 后台需要支持按款式配置区域 |
| 面料是否按区域限制 | 可能 | 建议后台预留区域和面料绑定能力，正式规则待确认 |
| 颜色是否跟随面料 | 是 | 选择某个面料后展示该面料可用颜色 |
| 图案能力是否按款式控制 | 不清楚 | 最简版可先支持，是否按款式关闭待确认 |
| 工艺是否按款式或图案限制 | 不清楚 | 最简版可先统一配置，是否限制待确认 |

## 5. 不纳入最简范围

| 功能 | 说明 |
| --- | --- |
| 支付 | 当前 demo 不涉及在线支付 |
| 物流 | 当前 demo 不涉及物流跟踪和发货管理 |
| 库存 | 当前 demo 不涉及真实库存扣减 |
| 发票 | 当前 demo 不涉及开票能力 |
| 优惠券/营销活动 | 当前 demo 不涉及营销促销 |
| 复杂会员体系 | 最简版凭证识别品牌，不做个人会员体系 |
| 复杂角色权限 | 可先不做多级角色和审批 |
| 询盘查看 | 不提供询盘列表、询盘详情、询盘跟进 |
| 数据报表 | 不提供销售、访问、转化等报表 |
| ERP/PLM/OMS 对接 | 当前阶段不纳入 |

## 6. 需要客户确认的问题

| 问题 | 当前建议 | 状态 |
| --- | --- | --- |
| 一个品牌是否可以有多个凭证 | 最简版支持一个或多个凭证均可，后台按品牌管理 | 待确认 |
| 凭证是否需要有效期 | 最简版先支持启用/停用，不做有效期 | 待确认 |
| 凭证进入后是否识别具体个人 | 最简版只识别品牌，不识别个人 | 待确认 |
| 品牌内容是否完全隔离 | 建议完全隔离 | 待确认 |
| 面料是否必须按区域限制 | 建议预留配置能力 | 待确认 |
| 图案能力是否按款式控制 | 最简版可先统一支持 | 待确认 |
| 工艺范围是否按款式或图案限制 | 最简版可先统一配置 | 待确认 |
