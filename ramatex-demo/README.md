# Ramatex Demo

Ramatex Demo 是一个服装独立站静态 demo，用于呈现公开首页、品牌空间、单款详情、面料详情和款式定制能力。

当前方案已收敛为公开站 + 品牌空间两个环境，以及款式详情、面料详情、定制器、选品篮和订单中心等核心页面。
页面支持中文和英文切换，默认中文。

当前实现保持纯静态，不引入 React、Ant Design 或构建工具。视觉系统以 `DESIGN.md` 为准，在 `styles.css` 中用 CSS token 模拟组件规范。

## 后续代码入口建议

正式开始实现时，优先保持纯静态结构：

```text
ramatex-demo/
  index.html
  brand-space.html
  styles.css
  app.js
```

当页面内容明显变复杂时，再拆分：

```text
ramatex-demo/
  index.html
  about.html
  products.html
  cases.html
  contact.html
  shared.css
  data.js
```

第一版不要过早引入构建工具，除非需要复杂组件化、路由或数据状态。

## 当前边界

- 第一版使用纯静态 `index.html`、`brand-space.html`、`styles.css`、`app.js`。
- 不引入 Ant Design；如需使用 Ant Design，需要迁移到 React 工程，本 demo 暂不采用。
- 颜色、字体、圆角、按钮、卡片、表单和弹窗样式以 `DESIGN.md` token 为准。
- 默认语言为中文，页面右上角可切换英文；也可以用 `?lang=en` 直接打开英文版。
- 当前 Banner、款式、视频和面料均已接入本地素材；公开站使用 `assets/banner/brand` 与 `assets/style/brand`，品牌空间使用 `assets/banner/nike` 与 `assets/style/nike`。
- 不确定最终品牌信息前，不编造具体公司数据。
- 所有页面可见文案应以真实服装网站语气表达，不出现 demo、mock、placeholder、local image、模块、链路、客户登录等说明型或后台型表达。
- 公开站顶部只保留 Logo、语言切换、品牌空间入口，不放中间栏目导航。
- 品牌空间从公开站右上角新开页进入，入口页使用访问凭证卡片；凭证可为空或任意输入，不做真实校验。
- 品牌空间凭证页不展示 Ramatex 相关字样，不做后台登录页，不出现账号、密码、验证码或忘记密码。
- 品牌空间顶部不放公开站或返回官网按钮，右侧入口为 `订单中心`。
- 公开站点击 `开始定制` 进入品牌空间访问凭证页；品牌空间内定制后加入 `选品篮`，在选品篮统一提交订单，并在订单中心查看订单。
- 首页只保留 Banner、款式、视频、面料四个主体区，底部使用常规网站 footer。
- 品牌空间只保留项目 Banner、款式、视频、面料四个主体区，底部使用常规网站 footer。
- Banner 按服装官网广告坑位处理：图片主导，自动 4 秒轮播；分页器保留 4 个短白条，当前短条内部显示 4 秒进度。
- 视频区使用本地 mp4 在页面内播放和切换，不以弹窗作为主交互；只允许主区域播放，缩略入口使用对应视频截帧封面，暂不提供视频更多列表。
- 款式、视频、面料使用 Notion 式浅底承托：Banner 下方整体为 `surface` 背景，款式和面料使用图片陈列卡，不使用大容器或双边框把卡片连接成列表盒子。
- `显示更多 >` 只用于款式和面料，并进入真实列表页：`#/styles`、`#/materials`。
- 头部使用白底和细 hairline，左右边距比主体内容更贴近视口；语言切换为低权重样式，品牌空间入口保持轻量入口感。
- 单款详情参考真实电商 PDP：左侧竖向缩略图和大图，返回入口统一显示 `返回` 并按来源返回首页、品牌首页或更多列表；PDP 顶部主体整体随页面滚动，不做左右分离 sticky；右侧商品信息只保留参考价、可选尺码、可定制内容和唯一主动作 `开始定制`，下方使用图文富文本承载完整尺码表和商品细节。
- 面料详情是资料页，不出现 `开始定制`、`加入选品篮`、数量或规格选择；图片切换方式和款式详情保持一致，右侧展示面料编号、成分、克重、幅宽、弹力、适用场景和纯色块可选颜色。
- 定制器使用一屏工作台结构：左/中为 3D 区域，右侧为唯一配置区；右侧宽度使用动态范围，最右侧竖向 rail 为 `面料 / 图案`，选中 tab 与面板同色、未选中 tab 使用浅灰底。面料按 `应用区域 -> 可选面料 -> 可选颜色` 联动；单个部位面料较多时使用抽屉内分页，每页 9 个，分页只显示 `当前页 / 总页数`，面料卡默认只显示图片，hover 用深色渐变遮罩显示名称和基础信息；颜色使用一行较大的纯色块，颜色过多时按一行分页。图案通过 `新增图案` 创建对象，对象内用 2x2 来源卡片选择图案库、上传图片、输入文字或 AI 生成，并用图示卡片选择工艺；输入文字支持字体 select、预设色和 Coloris 色盘选择；图案库每页 9 个且只显示图片不显示命名，分页只显示 `当前页 / 总页数`，AI 默认不显示结果，点击生成后桌面 4 个一行、小屏 2 个一行。右侧不放独立方案摘要，底部只保留 `加入选品篮`。
- 款式卡片桌面 4 列、手机 2 列，只保留图片和款名；面料卡片桌面 4 列、手机 2 列，只保留图片和面料名；hover 只做暗色名称遮罩和轻微反馈。
- 单款详情和定制器仍然是核心功能，不能删除。
