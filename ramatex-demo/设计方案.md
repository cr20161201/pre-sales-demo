# Ramatex 独立站 Demo 设计方案

## 1. 当前结论

Ramatex Demo 按真实服装独立站设计，不做说明型系统演示。页面需要让访客相信这是一个面向品牌方的服装开发与定制网站，文案和视觉都要贴近真实业务场景。

当前版本保持纯静态实现，不引入 React 或 Ant Design。颜色、字体、间距、圆角、按钮、卡片、表单、弹窗等视觉规则以 `DESIGN.md` 为准，并在 `styles.css` 中用 CSS token 实现。

本轮最新结论：

```text
公开站：面向普通访客，展示 Ramatex 的款式、视频、面料和定制能力。
品牌空间：面向 Nike、优衣库这类品牌方，展示专属空间内容。
单款详情：公开款式和品牌空间款式都必须先进入详情页。
定制器：保留为核心功能，承接单款详情后的配置动作。

面料详情：作为面料资料页承接面料卡片点击，只展示基础属性和可选颜色，不提供定制、选品篮或下单动作。
定制器右侧：`面料 / 图案` 使用一体化竖向 rail，选中 tab 与面板同色，未选中 tab 使用浅灰；面料和图案分页只显示 `当前页 / 总页数`。
```

页面结构收敛为：

```text
公开首页
品牌空间入口页
品牌空间首页
公开单款详情
公开定制器
品牌空间单款详情
品牌空间定制器
```

建议文件形态：

```text
index.html          公开站
brand-space.html    品牌空间，新开页打开
styles.css
app.js
```

公开站和品牌空间可以复用同一套样式、数据和渲染逻辑，但从产品感知上应像两个独立环境。

## 2. 顶部导航

### 2.1 公开站顶部

公开站顶部不放中间栏目导航，不展示 `款式 / 视频 / 面料`。

建议结构：

```text
左侧：RAMATEX
右侧：EN / 品牌空间
```

说明：

- `品牌空间` 是给品牌方进入专属内容的入口，不叫 `客户登录`。
- `品牌空间` 建议放在右侧，作为独立入口，而不是放在中间和首页平级。
- 点击 `品牌空间` 后新开页面进入 `brand-space.html`。
- 入口视觉要轻，不做大按钮，避免抢首屏 Banner。

英文：

```text
品牌空间 -> Brand Space
```

### 2.2 品牌空间顶部

品牌空间进入后不放 `公开站`、`返回官网` 这类按钮。

建议结构：

```text
左侧：BRAND SPACE
右侧：EN / 订单中心
```

说明：

- 品牌空间是品牌方的小站，不要在顶部持续提醒用户回到公开站。
- `订单中心` 用于查看已提交的选品订单。
- 不放中间导航；页面内容通过滚动组织。

## 3. 公开首页

公开首页保留四个主要内容区，再接常规网站 Footer。

```text
Home
  1. Banner 轮播
  2. 公开款式
  3. 视频
  4. 面料
  Footer
```

### 3.1 Banner 轮播

首屏必须是真正的服装官网 Banner，而不是左右分栏介绍区，也不是功能说明型 hero。

视觉要求：

- Banner 是纯广告坑位，全宽或接近全宽的大图为主。
- 图片或视频 poster 是主视觉，主题文字应像广告创意的一部分，放在图面内或贴近图面排版。
- 页面层不额外放标题、副标题、功能说明或按钮组，当前代码只保留图片和切换控制器。
- 整张 Banner 可以点击跳转到对应内容区或详情页。
- 控制器只保留极简圆点、短线或数字，不做大块 slide 信息条。
- 首屏需要有服装、上身、运动、面料或系列氛围，不用抽象背景。
- Banner 下方应露出下一屏一点内容，避免像封闭海报。
- Banner 下方主体区域使用浅 `surface` 背景统一承托；款式和面料使用独立图片陈列卡，不使用外层大白盒把卡片连接在一起；视频使用独立播放器容器。区块之间靠间距、背景层级和内容密度区分，不使用渐变背景或生硬横线。

建议 slide：

```text
TRAINING ESSENTIALS
STUDIO COLORWAYS
RUNWAY READY
ON BODY MOTION
```

文案方向：

```text
2026 春季 / 轻量训练系列
新配色 / 同款延展
造型系列 / 廓形与搭配
动态造型 / 上身、走秀、细节
```

Banner 不在页面外层单独放 `查看款式`、`查看视频`、`客户登录` 等按钮。

### 3.2 公开款式

款式区不是细长商品货架，应更像服装网站的精选款式陈列。

建议布局：

- 桌面端一行 4 个，手机端一行 2 个。
- 图片比例使用 `4:5`，像服装商品陈列，但不做细长货架。
- 卡片只展示图片和款名。
- 整张卡片可点击进入公开单款详情，不直接进入定制器。
- 不放品类、系列、卖点、标签、箭头、按钮或 hover 才出现的操作。
- hover 只做暗色名称遮罩和轻微反馈，不显示图标、价格、浏览量或其他数据。

建议款式：

```text
训练 T 恤
轻量训练夹克
针织连帽衫
Polo 衫
```

### 3.3 视频

视频区不跳走、不弹层播放。应使用本地 mp4 在当前区域内直接播放或切换。

建议布局：

```text
左侧 / 上方：大视频播放器
右侧 / 下方：视频 poster 列表
```

交互：

- 默认展示一个主视频，可静音、循环、自动播放。
- 点击视频 poster 后切换主播放器内容。
- 只有主播放器播放视频，缩略入口只展示对应视频截帧封面和播放符号。
- 点击缩略入口只切换主播放器，不重渲染整个页面。
- 如果暂时没有真实视频，可以先用 poster 模拟播放器状态，但交互仍按页面内播放器设计。
- 不使用弹窗作为视频区主交互。
- 缩略入口只展示视频画面和播放符号，不显示视频名称。

当前素材使用：

- 公开站 Banner 使用 `assets/banner/brand`。
- 品牌空间 Banner 使用 `assets/banner/nike`。
- 公开站款式使用 `assets/style/brand`。
- 品牌空间款式使用 `assets/style/nike`。
- 区块背景节奏固定为：Banner 后整体进入浅 `surface` 背景，款式和面料使用独立图片陈列卡，视频使用独立播放器容器；不使用渐变、粗横线或外层大卡片强行分区。
- 视频小卡不放视频名，只保留 poster 和播放符号。
- 主播放器只保留极短标题，不放“正在播放”和说明段落。
- 桌面端使用固定高度拼图：左侧大图与右侧三张 poster 总高度对齐。
- 右侧固定 3 张 poster，三等分高度，底边必须与左侧大图齐平。

内容方向：

```text
秀场影像
款式动态预览
AI 上身效果
面料动态细节
```

### 3.4 面辅料

面料区不沿用普通商品卡样式，应呈现面料质感、辅料细节和适用款式，不做商城式面料库。

建议布局：

- 桌面端一行 4 个，手机端一行 2 个。
- 图片比例使用 `1:1` 或近似方图。
- 卡片只展示图片和面料名。
- 点击面料进入面料详情页。
- 面料详情图片切换方式和款式详情保持一致，右侧展示面料编号、成分、克重、幅宽、弹力、适用场景和纯色块可选颜色。
- 面料详情不出现 `开始定制`、`加入选品篮`、数量选择或规格选择；面料替换仍在款式定制器里完成。
- 不放适用款式、性能标签、参数说明或长描述。

建议字段：

```text
面料名称
适用款式
特性标签：Breathable / Stretch / Soft Touch / Recycled
简短描述
```

### 3.5 Footer

公开首页底部使用常规网站 Footer，不放大号转化区。

不要放：

```text
获取报价大按钮
客户登录大按钮
品牌空间大 CTA
项目支持
客户经理
```

## 4. 品牌空间

品牌空间是给品牌客户使用的专属小站，不是普通商品列表，也不是后台。

推荐路径：

```text
公开站点击 Brand Space
  -> 新开 brand-space.html
  -> 品牌空间入口页
  -> 输入访问凭证并进入
  -> 品牌空间首页
```

### 4.1 品牌空间入口页

入口操作需要保留，但不做真实校验。

建议结构：

```text
标题：品牌空间
字段：访问凭证
按钮：进入
```

规则：

- 不展示 Ramatex 相关字样。
- 不展示账号、密码、验证码、忘记密码。
- 凭证可为空或任意输入，点击进入或回车进入品牌空间首页。
- 入口页使用居中访问卡片，卡片上方可放款式、面料、视频 poster 缩略图，不依赖大背景图。

英文：

```text
Brand Space
Access Code
Enter
```

### 4.2 品牌空间首页

品牌空间首页保留四个主体内容区：

```text
Brand Space
  1. 项目 Banner
  2. 款式
  3. 视频
  4. 面料
  Footer
```

#### 项目 Banner

用于展示品牌名、项目季节和项目内容状态。

示例：

```text
BRAND TRAINING 2026
春季训练 / 黑红主场系列
```

#### 款式

布局与公开款式一致，桌面端一行 4 个，手机端一行 2 个。

字段建议：

```text
款式名称
系列名称
状态：已推荐 / 待确认 / 可打样
MOQ
预计交期
```

交互：

- 点击进入品牌空间单款详情。
- 不从卡片直接跳定制器。

#### 品牌视频

使用页面内播放器，不弹层。

用途：

- 确认廓形、Logo 位置、主辅配色和穿着状态。
- 展示品牌空间系列的完整视觉方向。

#### 面料

展示已获批或推荐使用的面料。

字段建议：

```text
面料名称
适用款式
状态：已获批 / 推荐 / 可替换
特性：透气、弹力、再生、保暖等
```

### 4.3 品牌空间 Footer

品牌空间也使用常规网站 Footer。可以更简洁，但不要放 `公开站`、`返回官网`、项目支持或客户经理模块。

## 5. 核心功能页

### 5.1 公开单款详情

公开款式详情页参考真实商品详情页，但语气偏服装开发和定制，而不是普通零售下单。

字段建议：

```text
款式名称
款号
适用场景
可选尺码
可定制内容
AI 动态预览
按钮：开始定制
```

UI：

- 左侧商品大图，下方缩略图。
- 详情页返回入口统一显示为 `返回`，放在详情内容左上角，不放在右侧商品信息区。
- PDP 顶部主体是一个完整组件：缩略图栏、大图和右侧商品信息一起随页面滚动，不做左右分离的 sticky。
- 缩略图栏只保留图片切换，不放分享、收藏等额外操作。
- 右侧商品信息只保留短信息块：`可选尺码` 和 `可定制内容`，以及唯一主动作 `开始定制`。
- 右侧不做颜色、数量、面料选择，不固定展示某个面料，避免变成商城下单页。
- 下方使用图文富文本展示商品细节、完整尺码表、定制说明与交付信息。
- 详情页内的视频预览可以使用弹层或嵌入式预览；首页视频区必须页面内播放。

### 5.2 品牌空间单款详情

品牌空间详情页与公开详情页结构相似，但信息更偏 ToB 项目。

字段建议：

```text
品牌空间款式名称
项目系列
款号
MOQ
预计交期
可选尺码
可定制内容
AI 动态预览
按钮：进入定制
```

UI：

- 明显显示品牌空间语境，例如 `Brand Space`。
- 采购字段如 MOQ、交期、样衣状态可放在下方详情或项目说明中，右侧保持轻量。
- 不出现回到公开站的入口。

### 5.3 定制器

公开定制器和品牌空间定制器保留同一套专业配置器结构，差异在商品池和字段。定制页采用一屏工作台：左/中为 3D 区域，右侧为唯一配置区。

布局：

```text
左/中：3D 区域，真实开发接入 3D 组件
右侧：配置区，使用动态宽度；最右侧竖向 rail 为面料 / 图案，内容区随 rail 切换
顶部：只保留返回、款名、语言切换
```

公开定制器：

```text
选择面料
选择图案
加入选品篮
```

品牌空间定制器：

```text
选择面料
确认图案方案
填写尺码组和数量
加入选品篮
```

资源结构：

- 一级入口只保留 `面料 / 图案`。
- `面料 / 图案` 放在最右侧竖向 rail，不使用顶部横向 tab，方便后续扩展更多定制模块。
- 面料使用多个应用区域抽屉，每个抽屉内包含面料库和面料颜色选择；单个部位可选面料较多时使用抽屉内分页，每页 9 个，不做复杂筛选。单个面料可有多个颜色，颜色用方形纯色块展示。应用区域不等于结构改版，不表达领型、袖长、口袋等可改。
- 面料卡默认只显示图片，hover 时使用和首页一致的深色渐变遮罩显示面料名和基础信息；分页文案只显示 `1 / 2` 这类页码，不显示起止条数。
- 颜色选择使用一行较大的纯色块，颜色过多时按一行分页，不做多行堆叠。
- 图案不做区域概念，点击 `新增图案` 后生成一个可移动画布对象；每个对象内部再选择来源、图案内容和工艺，可删除，也可添加多个。
- 定制完成后加入选品篮，在选品篮统一提交订单，订单可在订单中心查看。
- 图案来源使用 2x2 卡片切换 `图案库 / 上传图片 / 输入文字 / AI 生成`，不再使用横向 tab。图案库展示图案卡；上传图片展示上传格子；输入文字展示文字输入、字体 select、预设色和 Coloris 色盘；AI 为文本输入生成 4 个结果。
- 图案库和面料库使用统一小卡规格，图案库每页 9 个且只显示图片，不显示图案命名。
- 图案库分页文案只显示 `当前页 / 总页数`，避免把资源数量信息放得过重。
- AI 生成默认不展示结果，点击生成后再显示 4 个结果；桌面 4 个一行，小屏 2 个一行。
- 工艺必须使用图示卡片，不使用 select。当前工艺方向为热转印、刺绣、硅胶章，视觉应像工艺样片而不是随意图标。
- 右侧不再放独立的当前方案摘要、面料配置摘要或已添加图案摘要；用户在当前 rail 内容中完成配置，底部只保留 `加入选品篮`。
- 顶部不放上一步、下一步、正面、背面、撤销、重做等工具；真实 3D 视角控制后续由 3D 组件内部承接。
- 页面本身不滚动；右侧配置区内部滚动。

## 6. 文案原则

页面可见文案必须像真实网站，不要像产品说明或内部评审材料。

禁止出现：

```text
demo
mock
placeholder
模块
链路
页面逻辑
先进入详情页
这个区域用于说明
静态演示
测试
客户登录
```

推荐语气：

```text
为品牌和团队打造可定制运动服装系列
基于成熟基础款快速开发新配色和系列延展
在打样前预览款式上身效果
进入品牌空间
为品牌空间准备的 2026 春季训练系列
项目面料库已准备
预计交期：样衣确认后 28-35 天
```

文案重点：

- 少讲系统能力，多讲业务结果。
- 少讲“功能”，多讲“款式、面料、视频、打样、交付”。
- 公开站称 `品牌空间`，不称 `客户登录`。
- 中文和英文都应模拟真实对外网站。

## 7. 第一版验收标准

- 公开首页首屏是真正的 Banner 轮播，不是左右分栏介绍区。
- 公开站顶部没有中间栏目导航，只保留 Logo、语言切换、品牌空间入口。
- `品牌空间` 点击后新开页面进入。
- 品牌空间入口页使用访问凭证卡片，凭证可为空或任意输入。
- 品牌空间顶部不出现 `公开站`、`返回官网`。
- 首页和品牌空间都只有 Banner、款式、视频、面料、常规 Footer。
- 款式卡片桌面 4 列、手机 2 列，只保留图片和款名。
- 视频区在页面内播放或切换，不以弹窗作为主交互。
- 面料卡片使用小型商品卡，桌面 4 列、手机 2 列，只保留图片和面料名。
- 单款详情和定制器保留，并能从公开款式和品牌空间款式进入。
- 页面文案不出现说明型、内部型、demo 型表达。
- 默认中文，英文版可切换且文案自然。
