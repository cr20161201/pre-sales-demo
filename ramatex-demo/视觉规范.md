# Ramatex Demo 视觉规范

## 1. 设计方向

Ramatex 独立站应呈现清爽、模块化、带有 Notion 式编辑感的服装网站气质。视觉重点不是解释系统能力，而是让品牌方看到真实款式、动态预览、面料和可定制空间。

关键词：

```text
clean sports fashion
modular apparel website
public collection showcase
brand projects collection
fabric and video focused
notion-style static tokens
```

## 2. 视觉原则

- 图片优先，必须能看出服装、面料、上身状态或系列氛围。
- 页面留白充足，信息密度适中。
- 使用清晰的栅格和稳定的模块节奏。
- 色彩严格以 `DESIGN.md` 为准：深蓝 hero、紫色主按钮、白色/米灰 surface、细 hairline。
- 首页按 Banner、款式、视频、面料组织；品牌空间按项目 Banner、款式、视频、面料组织。
- 首屏必须是真正的服装官网 Banner，不做左右分栏介绍区，也不做功能说明型 hero。
- 不做纯模板感 hero，不用无业务含义的抽象背景。
- 不做后台系统感；可以使用 `DESIGN.md` 的深蓝和紫色，但不要做科技感渐变，也不做奢侈品黑金风。

## 3. 色彩建议

当前 demo 的视觉 token 以 `DESIGN.md` 为准，不再使用旧的绿色运动风基线。

| 用途 | 建议色值 | 说明 |
| --- | --- | --- |
| 页面背景 | `#ffffff` | Canvas White |
| 浅色分区 | `#f6f5f4` | Surface |
| 主文字 | `#1a1a1a` | Ink |
| 正文 | `#37352f` | Charcoal |
| 辅助文字 | `#787671` | Steel |
| 分割线 | `#e5e3df` | Hairline |
| Hero 深色 | `#0a1530` | Brand Navy |
| 主按钮 | `#5645d4` | Primary Purple |
| 主按钮按下 | `#4534b3` | Primary Pressed |
| Pastel 卡片 | `#ffe8d4` / `#fde0ec` / `#d9f3e1` / `#e6e0f5` / `#dcecfa` | Feature tint |

使用规则：

- Banner 使用 `#0a1530` 深蓝 hero band，服装图片作为图面主视觉。
- 主按钮统一使用 `#5645d4` 紫色矩形按钮。
- 款式、视频、面料区块应保持不同视觉节奏，避免整站都是同一种卡片。
- 品牌空间可以比公开首页更安静、更私域，但仍然要有服装 campaign 感。

## 4. 字体建议

网站 demo 使用 Inter / Notion Sans fallback，保证本地打开稳定。

```css
--font-body: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif;
--font-display: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif;
```

如果后续需要更强品牌感，可再引入网页字体。

## 5. 字号层级

桌面端：

| 用途 | 建议字号 |
| --- | --- |
| Banner campaign 字样 | 52px-88px |
| Banner 辅助字样 | 16px-24px |
| 页面大标题 | 40px-52px |
| Section 标题 | 28px-36px |
| 卡片标题 | 18px-22px |
| 正文 | 15px-17px |
| 辅助文字 | 13px-14px |

移动端：

| 用途 | 建议字号 |
| --- | --- |
| Banner campaign 字样 | 42px-64px |
| Banner 辅助字样 | 16px-18px |
| Section 标题 | 26px-32px |
| 卡片标题 | 18px-20px |
| 正文 | 15px-16px |

规则：

- 不用视口宽度直接缩放字体。
- 字重层级少而明确。
- 英文页面避免负 letter-spacing。

## 6. 布局规范

桌面端：

- 内容最大宽度建议 `1180px-1280px`。
- Banner 下方主体区域使用 `surface` 浅背景承托，Section 上下间距建议 `24px-44px`，相邻区块顶部继续收紧。
- 款式和面料在桌面端优先 4 列，移动端 2 列。
- 首屏需要露出下一屏一点内容，避免像封闭海报。
- Banner 是广告坑位，页面外层不放大段标题、副标题、功能说明或 CTA 按钮组。
- Banner 文字应来自图片素材本身，页面层不再额外叠加标题、副标题或按钮组。
- Banner 高度控制为上一版约 `3/4`，自动 4 秒轮播；控制器保留 4 个极简短线，当前短线内部显示 4 秒填充进度。
- 首页模块顺序固定为 Banner、款式、视频、面料、Footer。
- 品牌空间模块顺序固定为项目 Banner、款式、视频、面料、Footer。
- 区块背景节奏固定为：Banner 后整体进入浅 `surface` 背景，款式和面料卡片必须彼此独立，不使用外层大白盒连接；视频使用独立播放器容器；不使用渐变背景带，也不靠生硬横线分隔区域。款式、视频、面料模块之间主要间距约 `60px`。
- Footer 使用常规网站底部，不做大号转化 CTA。
- 公开站顶部不放中间栏目导航，只保留 Logo、语言切换和品牌空间入口；头部使用白底、细 hairline，并比主体内容更贴近视口左右边缘。
- 语言切换视觉权重低于品牌空间入口；品牌空间入口使用轻量文字/soft button，不做大按钮 CTA。
- 品牌空间顶部不放公开站或返回官网入口。

移动端：

- 页面左右边距建议 `20px-24px`。
- 多列内容改为单列。
- 图片和文字模块顺序应符合阅读路径。
- CTA 按钮应容易点击，触控高度不低于 `44px`。

## 7. 组件规范

### 7.1 顶部与按钮

公开站顶部：

```text
RAMATEX
EN / 品牌空间
```

品牌空间顶部：

```text
BRAND SPACE
EN / 订单中心
```

规则：

- `品牌空间` 放右侧，作为品牌方专属入口。
- 不使用 `客户登录` 文案。
- 品牌空间入口建议轻量 soft button，避免抢 Banner 主视觉。
- 品牌空间新开页进入。

按钮类型：

- Primary：深底或品牌强调色，用于进入详情、开始定制、加入选品篮、提交订单等真实动作。
- Secondary：白底细边框，用于查看详情。
- Text link：用于低权重跳转。

规则：

- 同一区域最多一个主要按钮。
- 按钮文案使用动作动词。
- 按钮圆角建议 `6px-8px`。
- 首页底部不放 `获取报价 / 客户登录 / 品牌空间` 大 CTA。
- `显示更多 >` 使用轻量文本链接，不使用大按钮、描边按钮或重背景。

### 7.2 卡片

卡片只用于：

- 款式条目
- 视频条目
- 面料条目
- 单款详情中的信息组
- 定制器选项

规则：

- 按钮圆角 `8px`，卡片圆角 `12px`。
- 不做卡片套卡片。
- 表单、弹层和重点信息卡可使用 `#e5e3df` hairline 边框；首页款式和面料优先使用图片陈列卡，不做厚白底、粗边框或双边框。
- 款式卡片桌面 4 列、移动端 2 列，图片比例使用 `4:5`，只展示图片和款名。
- 款式卡片不放箭头、按钮、标签、品类、系列或 hover 才出现的操作。
- 款式和面料使用图片陈列卡：默认无厚白底、无双边框、低 padding；hover 只显示名称遮罩和轻微反馈，不显示图标、价格、浏览量或其他数据。
- 视频切换卡只保留 poster 和播放符号，不放视频名。
- 面料卡片使用小型商品卡，桌面 4 列、移动端 2 列，只展示图片和面料名。
- 面料卡片不放适用款式、性能标签、参数说明或长描述。
- 面料详情页使用和款式详情一致的详情结构：左侧缩略图栏、中间大图、右侧基础属性与纯色块可选颜色；不放定制按钮、选品篮按钮、数量控件或规格选择。

### 7.3 视频播放器

视频区应使用本地 mp4 在页面内播放或切换，不以弹窗作为主交互。只有主区域播放视频，缩略入口只展示对应视频截帧封面和播放符号。

建议结构：

```text
大播放器
视频 poster 卡片
```

规则：

- 大播放器使用 `16:9`。
- 可静音、循环、自动播放。
- 点击视频 poster 切换主播放器内容。
- 如果没有真实视频，先使用视频 poster 模拟，但版式仍按播放器设计。
- 桌面端视频区是一个固定高度拼图，左侧主视频和右侧三张视频缩略入口必须等高对齐。
- 右侧 poster 固定 3 张，三等分高度，不允许自然流把底部撑开或留下大空白。

### 7.4 表单与品牌空间入口

表单和输入项主要出现在定制器里，应让采购方觉得可靠。

定制器采用一屏工作台：

- 顶部只保留返回、款名和语言切换，不放上一步、下一步、正面、背面、撤销、重做等工具。
- 左/中是 3D 区域，不额外放说明或资源标签；当前 demo 用商品图占位，真实开发接入 3D 组件。
- 右侧为唯一配置区，使用动态宽度范围；最右侧使用竖向 rail 切换 `面料 / 图案`，不使用顶部横向 tab。
- 面料使用多个应用区域抽屉，每个抽屉内包含面料库和单个面料的多色选择；单个部位面料较多时使用抽屉内分页，每页 9 个，不做复杂筛选。颜色用紧凑方形纯色块，不使用占位很大的颜色按钮。应用区域只表达材质作用范围，不表达领型、袖长、口袋等结构可改。
- 面料分页只显示 `当前页 / 总页数`，不显示起止条数；定制器内面料卡片默认只显示图片，hover 时使用和首页一致的深色渐变遮罩显示面料名和基础信息。
- 颜色选择使用一行较大的纯色块，颜色过多时按一行分页，不做多行堆叠。
- 图案通过 `新增图案` 创建对象；每个对象内部用 2x2 来源卡片切换图案库、上传图片、输入文字和 AI 生成，图案作为可移动画布对象，不做区域概念，可添加多个并可删除。输入文字使用字体 select，颜色使用预设色块和 Coloris 色盘。图案库使用和面料库一致的小卡与分页，每页 9 个，只显示图片不显示命名。
- 图案分页只显示 `当前页 / 总页数`；图案库卡片不显示命名，避免出现不适合品牌语境的抽象名称。
- AI 生成默认不显示结果，点击生成后显示 4 个结果；桌面一行 4 个，小屏一行 2 个。
- 工艺使用图示样片卡片选择，不使用 select。
- 右侧 `面料 / 图案` rail 和内容面板必须是一体化视觉：选中 tab 与内容面板同色，未选中 tab 使用更深一点的浅灰底，选中 tab 保留圆角外侧，不出现黑色竖条或独立按钮感。
- 右侧不放独立的当前方案摘要、面料配置摘要或已添加图案摘要，底部只保留 `加入选品篮`。
- 页面本身不滚动；右侧配置区内容过多时在右侧内部滚动。

品牌空间入口页使用访问凭证卡片，但不做真实校验。

入口页建议：

```text
品牌空间
访问凭证
进入
```

入口页不显示 Ramatex 相关字样，不做后台登录页样式，不出现账号、密码、验证码、忘记密码。凭证可为空或任意输入，点击进入或回车进入品牌空间。

字段要求：

- label 清晰
- 必填状态明确
- focus 状态可见
- 错误状态可见
- 提交状态有反馈

## 8. 图片规范

建议比例：

| 用途 | 比例 |
| --- | --- |
| Banner 主图 | 全宽裁切、`16:9`、`16:10` |
| 产品图 | `4:5` |
| Banner slide | 全宽裁切、`16:9` |
| 视频 poster | `16:9` 或 `16:10` |
| 面料卡片 | `1:1` |
| 工厂 / 能力图 | `16:9` |
| 案例图 | `4:3` |
| 团队 / 关于图 | `3:2` |

图片处理：

- 保持主体清晰。
- 不过度加暗色蒙层。
- 不使用看不清产品的氛围图作为核心图。
- 同组图片色温和裁切尽量一致。
- 首页素材优先级为：服装上身图、走秀/动态视频 poster、款式平铺图、面料细节图。
- 当前版本已接入本地 Banner、款式、视频和面料素材；后续替换素材时保持同样目录分层。
- 品牌空间素材需要有“为某个品牌准备的一组系列”的感觉，不要像散乱商品列表。

## 9. 动效规范

动效只用于帮助理解层级和反馈。

允许：

- hover 只做暗色名称遮罩、轻微透明度或色彩反馈，款式卡片不做位移，不显示图标、价格、箭头或数据。
- 菜单展开收起
- 锚点滚动
- 表单状态过渡
- Banner 手动切换
- 视频区页面内切换播放

避免：

- 大面积滚动视差
- 自动播放复杂动画
- 首屏文字入场过慢
- 影响阅读的循环动效
- 视频点击后跳出当前页面
