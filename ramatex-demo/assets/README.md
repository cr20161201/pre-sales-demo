# Assets

素材按用途归档，避免后续页面实现时路径混乱。

```text
assets/
  brand/      品牌标识、品牌图形、品牌色参考
  products/   产品、材料、服务成果图
  factory/    工厂、产线、工艺、质检、仓储
  cases/      客户案例、应用场景、交付结果
  team/       团队、办公、展会、沟通场景
```

## 命名建议

使用英文小写和连字符：

```text
brand-logo-green.png
product-recycled-yarn-01.jpg
factory-quality-check-01.jpg
case-hotel-uniform-01.jpg
team-sales-meeting-01.jpg
```

## 素材记录

每批素材应记录：

- 来源
- 是否可对外展示
- 拍摄 / 生成时间
- 对应页面或模块
- 是否需要压缩

最终演示前，需要确认所有页面引用图片都能正常加载。
