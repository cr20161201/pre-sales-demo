移动端录入页首次打开会自动载入一款演示数据：包含 1 个方案、2 条修改项、2 套颜色和数量合计 3 件，方便直接验收；清空或保存后按用户操作继续。

订单结果：移动端默认展示前 3 个方案简介，支持原地展开及进入单方案详情；PC 保留原产品表格，在选款信息列打开抽屉，直接展示全部方案简介。详情包含修改项、独立颜色表格、方案资料及图片。返回保留列表位置，图片支持预览。各页面直接加载固定示例，不读取录入页提交数据，详见 [ORDER-DISPLAY.md](ORDER-DISPLAY.md)。

录入按方案组织修改内容、款式颜色与方案资料，图片区分方案图片及修改项附图。小程序通过订单底部编辑入口修改，保存后返回订单详情。

当前入口：`index.html` 为页面导航，`mobile.html` 为小程序录入页，`analytics.html#products` 和 `analytics.html#notes` 分别进入选款分析与修改分析。入口链接均在新标签页打开。 `advice-config.html` 为 Cloud 端修改内容类别配置页，入口已加入 `index.html`。

## 演示路径

1. 点击“设置报价、具体需求”，填写报价、币种、起订量、备注，多选需求并调整数量，点击“确定”。关闭弹层不保存本次编辑。
2. 报价弹层内点击“修改内容”直接进入录入页。上方为已有修改内容的折叠摘要，下方始终显示单条表单；“保存并继续添加”把当前条目加入摘要并清空表单，“保存并返回”直接回到报价弹层。点击摘要可在同一个表单编辑或删除。未保存时切换、返回都会提示保留或放弃。最后在报价弹层点“确定”统一确认本次选品编辑。
3. 客户信息支持手工输入、选择示例客户、文本提取和名片识别演示。
4. “暂存”和“提交”仅显示演示反馈；刷新恢复固定示例。
5. 填齐客户必填资料，点击“确认下单”，核对后创建演示订单。
6. 右上角“•••”→“恢复初始演示”，可重置至截图初始状态。

名片识别使用示例结果，无 OCR 接口；文本识别为本地格式提取。下单仅展示成功结果，不连接业务系统。编辑和图片仅保留在当前页面，刷新恢复示例。照片在本地压缩，每条最多 6 张。手机拍照使用系统图片选择器，是否直接打开相机取决于浏览器。名片图片不上传。两条面料记录及成分来自参考截图；面料图片为本地近似绘制，尚缺截图中的独立原图。
