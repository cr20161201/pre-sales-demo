# 代客选品 · 手机端 Demo

另有独立桌面端数据后台：[analytics.html](analytics.html)，访问 http://localhost:5188/analytics.html 。包含款式选品分析、款式修改分析、客户选品分析、客户修改分析，数据来源在右上角，详见 [ANALYTICS.md](ANALYTICS.md)。

当前修改建议流程：上方录入、下方已录入列表。点“添加到列表”连续新增，保留类别并清空文字和照片；点击已有条目回填编辑，点“保存修改”更新。底部“完成”返回报价弹层，未添加的内容会提示先处理。照片入口为单个加号，点击后打开“拍照 / 从相册选择 / 取消”菜单。此版本以 `tests/entry-first-check.js` 和 `evidence/entry-first.png`、`evidence/photo-menu.png` 为准，下文较早版本的双按钮操作已替换。

根据用户提供的两张小程序截图，复刻选品录入页和洽谈信息弹层。纯 HTML / CSS / JavaScript，无构建、无外部依赖。

## 打开

直接双击 `index.html`，或运行：

```sh
cd /Users/cr_weng/code/pre-sales-demo/assisted-selection-demo
python3 -m http.server 5188
```

访问 http://localhost:5188 。桌面显示居中的手机宽度页面，手机自适应。推荐以 400 × 880 查看截图对应排版；较矮屏幕的内容区支持滚动，操作按钮始终固定底部。

## 演示路径

1. 点击“设置报价、具体需求”，填写报价、币种、起订量、备注，多选需求并调整数量，点击“确定”。关闭弹层不保存本次编辑。
2. 报价弹层内点击“修改建议”直接进入录入页。上方为已有建议的折叠摘要，下方始终显示单条表单；“保存并继续添加”把当前条目加入摘要并清空表单，“保存并返回”直接回到报价弹层。点击摘要可在同一个表单编辑或删除。未保存时切换、返回都会提示保留或放弃。最后在报价弹层点“确定”统一确认本次选品编辑。
3. 客户信息支持手工输入、选择示例客户、文本提取和名片识别演示。
4. 点击“暂存”，刷新后恢复选品与客户资料。
5. 填齐客户必填资料，点击“确认下单”，核对后创建演示订单。
6. 右上角“•••”→“恢复初始演示”，可重置至截图初始状态。

名片识别使用示例结果，无 OCR 接口；文本识别为本地格式提取。下单仅展示成功结果，不连接业务系统。暂存限当前浏览器和访问地址，包含修改建议和照片。照片在本地压缩，每条最多 6 张；浏览器存储空间不足时会提示暂存失败。手机拍照使用系统图片选择器，是否直接打开相机取决于浏览器。名片图片不上传。两条面料记录及成分来自参考截图；面料图片为本地近似绘制，尚缺截图中的独立原图。

## 文件

- `index.html` / `styles.css`：主页面和手机布局
- `app.js`：交互和浏览器暂存
- `config.js`：产品、需求、示例客户配置
- `assets/manifest.json`：素材来源
- `DESIGN.md`：视觉依据
- `evidence/`：实机浏览器尺寸截图与检查记录
- `tests/browser-check.js`：浏览器页面内执行的交互验收脚本；仅用于独立测试会话，会修改该测试会话的演示数据
