# Design Notes

## 画布

- 基准尺寸：`1215 × 2160`
- 页面在任意视口中按比例整体缩放，不改变内部布局比例。
- 目标设备为触控竖屏，核心按钮触控高度不低于 54px，不依赖 hover。

## 信息层级

- 入口页只承担设备与 API 预检，不做营销式首页。
- 实时页将 69% 垂直空间用于生成画面，底部固定款式轨道。
- 本地摄像头是对照信息，以右上小窗展示；接口诊断默认收起。

## 视觉方向

- 延续 SUMEC Demo 的克制、偏工作台式界面。
- 使用中性灰白、深绿和状态色，不使用装饰性渐变或悬浮卡片堆叠。
- 款式图使用 `contain`，避免为了填满卡片而裁切服装。
