# 产品方案

## 目标

用最短链路验证 Xmax 实时试衣 API 在 55 寸竖屏设备上的摄像头接入、生成质量、响应速度和连续切款效果。该页面是接口测试 Demo，不承担完整商品库、会员或结果保存业务。

## 用户链路

1. 入口页检查永久 Key、款式素材和浏览器安全环境。
2. 用户点击“打开实时试衣”，浏览器申请摄像头权限。
3. 服务端用永久 Key 签发临时 Key，前端上传当前款式并建立实时会话。
4. 用户在底部款式轨道直接切换服装，远程画面保持连续。
5. 用户点击“结束体验”，释放摄像头和实时连接。

## 状态与异常

- 未配置：明确指出缺 Key、缺素材或非安全环境，禁用启动。
- 准备中：分别展示凭证、上传、连接和切款状态。
- 运行中：主画面展示远程生成结果，小窗保留本地摄像头对照。
- 失败：展示真实错误和重新连接入口，不伪造结果。
- 诊断：可展开查看最近会话事件，用于现场定位网络、权限和 API 问题。

## 非目标

- 不内置 Mock 或预制合成视频。
- 不把永久 Key 放入浏览器。
- 不实现账号、订单、报告、扫码下载等正式产品能力。
