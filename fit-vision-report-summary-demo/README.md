# Fit Vision Report Summary Demo

Standalone visual prototype for testing summary-first report content and expanded recommendations without changing the Fit Vision application.

- `摘要`: shows the scan-friendly report.
- `全部内容`: expands the original analysis details.
- Theme follows the operating system with `prefers-color-scheme`.
- The report previews complete Look imagery and multi-item outfit compositions.
- `查看全部推荐`: opens `recommendations.html`, with outfit/item tabs, filters, and load-more behavior.
- Try-on buttons show Demo feedback without starting a real try-on flow.

Open `index.html` directly or serve this directory with a local HTTP server.
