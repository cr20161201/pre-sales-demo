# 苏美达智能创款与试衣 Demo 产品方案

## 1. 项目目标

本项目面向 55 寸竖屏触控终端，演示从智能诊断、推荐款式到面料创款和试衣的完整链路。交付为纯 HTML/CSS/JavaScript 静态 Demo，不依赖后端或 AI 接口，可直接打开 `index.html`。

## 2. 范围标识

- **Demo 已实现**：真实可点击，由前端状态和本地素材完成。
- **Demo 模拟实现**：完整呈现交互，结果来自预制素材。
- **完整版规划**：正式产品需要后端、算法或硬件能力支持。

## 3. 信息架构

首页包含智能推荐、自主创款两个一级入口。两条链路共享本次照片、本次方案和本次试穿记录。关联搭配不在本版范围内。

## 4. 智能推荐

流程：图像授权 → 模拟拍照 → 报告生成 → 美学报告内选择或扫码款式 → 款式详情 → 更换面料 / 图片试穿 / 实时试穿。

### Demo 已实现

- 正式语气的图像采集与隐私授权页面。
- 基础特征、风格定位、推荐款式和穿搭建议报告。
- 报告内推荐款式、扫码选款和款式大图详情，避免重复进入内容相同的推荐列表页。
- 同款多面料方案保留与缩略图切换；已生成组合直接复用。
- 图片试穿和实时试穿两个直接操作入口，无方式选择中间页。
- 诊断照片在后续图片试穿中复用。

### Demo 模拟实现

- 诊断、推荐、面料创款结果来自静态配置。
- 图片试穿、生成视频和实时试穿使用预制图片或视频。

### 完整版规划

- 真实人体与风格诊断算法。
- 动态推荐排序和商品、库存系统对接。
- 真实面料换款生成、图片试穿与实时服装跟踪。

## 5. 自主创款

页面采用左侧结果画布、右侧素材库布局。款式库和面料库可任意顺序选择；两项齐全后自动匹配组合结果。

### Demo 已实现

- 款式和面料任意顺序选择、移除和替换。
- 已配置组合的生成反馈和本次方案保存。
- 查看方案并恢复已有作品。
- 图片试穿与实时试穿直接入口。
- 自主链路未拍照时，在图片试穿前补充一次拍照；之后复用。

### 完整版规划

- AI 创款、局部编辑及更多生成状态。
- 跨会话作品保存、用户账户和云端同步。
- 两件自主设计作品的自由搭配；本 Demo 暂不实现搭配能力。

## 6. 款式详情与方案版本

- 款式详情与试穿结果共用“主视觉 + 连续工作台”两段式结构，避免主图、缩略图和信息卡片互相割裂。
- 主视觉约占页面内容高度的 70%，工作台约占 30%，两部分直接衔接。
- 工作台左侧保留原款及本次生成的所有面料版本，右侧集中显示当前标签信息和操作。
- 已完成版本使用款式结果缩略图，生成中版本使用面料缩略图。
- 页面不提供额外的“+”入口；“更换面料”是唯一的新版本入口。
- 选择本次已生成的面料时直接切换已有方案，不重复生成。
- 主图和工作台尺寸固定，切换不同图片、生成状态或视频时不改变布局。

### 产品信息边界

- 款式业务字段仅使用：样衣编号、品名、颜色、尺码、所属部门、国别和二维码。
- 面料业务字段仅使用：Art No、Name、Comp、Cons、Wt(gsm)、Wid(cm)、Remark、Area 和二维码。
- 图片路径、内部 ID、组合映射、试穿素材和视频属于技术字段，不作为产品信息展示。
- 智能推荐结论只在报告语境中呈现，不写入款式基础信息；缺失字段直接隐藏，不补写推测内容。

## 7. 背景选择与图片试穿

详情页进入图片试穿前必须选择背景。自主创款没有照片时，流程为拍照 → 选择背景 → 试穿结果；已有照片时直接进入背景选择。

背景选项采用三列多行的竖图网格。背景素材保持正常竖版比例，不拉伸为纵向长条；确认操作固定在页面底部。

### Demo 已实现

- 6 个真实环境背景选项及上次背景预选；55 寸竖屏每行展示 3 个，形成两行。
- 背景素材统一位于 `assets/backgrounds`，使用 `3:4` 竖版预览框和 `object-fit: cover` 控制裁切。
- `背景 ID → 背景素材`、`方案 + 背景 ID → 试穿结果素材` 的配置关系。
- 本次试穿记录可保存多款、多背景的图片、生成视频与实时结果。
- 单个图片结果支持换背景和生成视频，均新增结果而不覆盖原结果。
- 同一图片结果重复生成视频时直接复用已有视频。

### 结果页后续动作

- `查看方案`：选择本次已有方案并沿用当前背景，直接生成或打开试穿结果。
- `继续新设计`：返回款式详情，不自动打开面料库。
- `换其他推荐款`：返回报告；从报告选择款式后重新进入详情及背景选择链路。

### 试穿结果布局

- 结果页与款式详情共用同一套“主视觉 + 连续工作台”框架。
- 主视觉不放款式说明浮层，避免遮挡试穿图片或视频。
- 工作台左侧显示本次访问产生的全部图片、视频和实时试穿结果。
- 工作台右侧紧凑显示当前标签字段、换背景、生成视频和后续操作，不使用贯穿下半页的长侧栏。

## 8. 实时试穿

- 视频全屏铺满，方案列表以浮窗呈现。
- 浮窗包含本次体验创作过的全部方案，可直接切换。
- 底部仅保留返回报告和返回首页。
- 自主链路尚未生成报告时，返回报告会先进入报告生成流程。
- 实时试穿与图片结果生成视频是两项独立能力。

## 9. 扫码选择实物款式

### Demo 已实现

- 美学报告推荐区域和自主创款款式库均提供扫码选款入口。
- 扫描界面、扫描反馈和预设样品码匹配。
- `sampleCode → styleId` 的正式配置关系。

### 完整版规划

- 接入摄像头二维码或条码解析。
- 对接真实样品、商品、库存与门店系统。
- 无效码、停用码、跨门店码等业务校验。

## 10. 正式数据关系

配置文件 `sumeida-config.js` 维护：

```text
sampleCode → styleId
styleId + fabricId → combination
backgroundId → background asset
combination + backgroundId → image try-on asset
combination → generated video / realtime media
```

配置中的款式字段使用 `sampleNo / name / color / size / department / country`；面料字段使用 `artNo / name / comp / cons / weightGsm / widthCm / remark / area`。页面不得读取未列入实物标签范围的产品描述字段。

组合指纹用于正式版查询已有生成结果或缓存；本次方案是用户可见的会话创作记录；本次试穿是当前访问产生的所有图片、视频和实时结果。三者职责独立。

## 11. 素材规范

正式目录为 `assets/styles`、`assets/fabrics`、`assets/combinations`、`assets/backgrounds`、`assets/tryon`、`assets/realtime`、`assets/qrcodes` 和 `assets/report`。背景预览复用 Fit Vision 正式场景素材并保存为项目本地文件，后续替换只需更新配置和文件，不修改页面逻辑。

## 12. 验收标准

- 直接打开 `index.html` 可进入首页，小屏浏览器能完整显示固定画布。
- 两条主链路均可完整点击，不出现关联搭配或试穿方式中间页。
- 同款多面料方案不会互相覆盖，已有组合不会重复生成。
- 图片试穿包含背景选择、本次记录、换背景、生成视频和查看方案。
- 款式详情和试穿结果使用同一套连续工作台结构，不出现说明浮层、割裂卡片或空白长侧栏。
- 背景选择页一行 3 个正常比例竖图，首版 6 个背景完整形成两行。
- 款式、面料页面不得展示实物标签范围之外的产品业务字段。
- 实时试穿为全屏视频与本次方案浮窗，返回报告和首页可用。
- 扫码、照片复用及自主链路补拍逻辑有明确反馈。
- 正式素材替换不需要修改业务页面代码。
