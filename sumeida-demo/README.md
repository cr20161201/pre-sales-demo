# Sumeida Demo

苏美达智能推荐、创款与试衣静态演示。

## 打开方式

直接双击 `index.html`，或将整个 `sumeida-demo` 目录交付到展示设备后使用浏览器打开。

页面使用固定 `1215 × 2160` 竖屏画布并自动等比缩放。普通电脑的小窗口会完整显示整块界面，不需要开启浏览器设备模拟；展示设备全屏时会自动放大到可用区域。

## 当前内容

- 智能推荐：拍照、美学报告、查看更多推荐、款式详情、多面料方案和试穿。
- 款式库：款式与面料选择、本地图片上传、自动组合、本次方案、扫码选款/选料和试穿。
- 图片试穿：单件试穿或手动搭配、直接生成预制结果、本次记录、生成视频和扫码带走。
- 手机结果页：静态结果集浏览、翻页和图片下载演示。
- 实时试穿：全屏视频、本次方案浮窗、返回报告和结束体验。
- 素材与关系：由 `sumeida-config.js` 集中配置。
- 产品边界：详见 `产品方案.md`。

## Demo 说明

本版本不调用 AI 或后端接口。诊断、组合款、图片试穿、生成视频和实时试穿均使用本地预制素材模拟，页面中已标注预制或演示状态。扫码带走使用静态手机结果页，不与大屏当前会话同步；本地上传素材仅在当前页面会话中有效。

正式素材替换时，请保持 `assets/` 分类和稳定 ID，仅更新素材文件与 `sumeida-config.js` 的对应关系。
