VTON Benchmark

Xmax ClothX 与 Decart Lucy VTON 独立对比测试台

标准对比

运行 npm run benchmark。系统使用同一视频和服装素材，依次测试两家，避免同时推流造成资源竞争。

原始证据写入 runs/<run-id>/，阅读报告单独写入 reports/<run-id>/comparison.md。

单项预览

运行 Xmax 运行 Decart

运行条件

  • assets/test-clip.mp4 — 人物测试视频（业务素材）
  • assets/garment.jpg — 白底服装参考图（可选第二套 garment-b.jpg 测换装切换）
  • .env — 填好 XMAX_API_KEY 与 DECART_API_KEY（主 Key 只在本机 server 读取）
  • 固定视频用于公平复测；真实摄像头测试应作为另一组记录，不与固定视频结果混算
